# Skill and Tool

这个仓库用来存放和整理 Skill、工具、研究资料及其版本记录。内容按来源保留，方便以后查找、更新和复核。

仓库只保存资料。各项目的使用条件以原项目说明为准。

## 从哪里开始

| 文件 | 内容 |
|------|------|
| [REPOSITORIES.md](REPOSITORIES.md) | 一级 Git 仓库的来源、分支、提交和同步状态 |
| [REPOSITORY_MANAGEMENT.md](REPOSITORY_MANAGEMENT.md) | 批量拉取、目录整理、检索与知识图谱工具说明 |
| [SKILLS_INDEX.md](SKILLS_INDEX.md) | Skill 数量、分类和用途索引 |
| [BROWSER_AUTOMATION_COMPARISON.md](BROWSER_AUTOMATION_COMPARISON.md) | 浏览器控制、网页快照与像素截图理解工具对比 |
| [GITHUB_REPOS.md](GITHUB_REPOS.md) | 各批次下载、更新和检查记录 |
| [GITHUB_STAR_LIST.md](GITHUB_STAR_LIST.md) | GitHub 项目链接清单 |
| [CHANGELOG.md](CHANGELOG.md) | 这个存放库的变更记录 |

早期整理内容保存在 [README_ARCHIVE.md](README_ARCHIVE.md)。

## 仓库里保存的内容

| 目录 | 说明 |
|------|------|
| [multi-search-engine](multi-search-engine/) | Multi Search Engine 的单文件 Skill 快照和来源说明 |
| [zhihu-cli-skill](zhihu-cli-skill/) | 知乎 CLI Skill 及配套脚本和参考文档 |

第三方 Git 项目主要记录在 [REPOSITORIES.md](REPOSITORIES.md)。表中保留上游地址和扫描时的提交号，需要完整内容时可以按记录重新克隆。

## 收录规则

- 记录来源、用途和当前提交。
- 已存在的项目先检查上游更新，再刷新索引。
- 单独保存的文件附带来源说明。
- 第三方内容沿用各自的许可证和使用条件。

统计数字对应各次扫描结果。上游项目继续变化时，以来源仓库为准。
